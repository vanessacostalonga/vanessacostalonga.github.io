# Vanessa Costalonga — Editorial portfolio, v4

A static multi-page website for GitHub Pages. This version recreates the approved visual direction: oversized dark serif name over photographs, a neutral off-white background, and a minimal, clickable navigation.

## How to preview
Open `index.html` in a browser. Follow Work, News, Teaching, Publications, About, and Contact to their own pages. Clicking either part of the big name returns to Home.

## How to publish
Upload **the contents of this directory** into the root of your GitHub Pages repository. Keep `index.html` and the other HTML pages at the repository root and keep the `assets` folder next to them.

## Change the hero images
In `index.html`, replace:
- `assets/brick-study.jpg` (large centre photo)
- `assets/timber-joint.jpg` (top-right photo)
- `assets/printed-material.jpg` (small bottom-left photo)

You can use the same filenames for your own photographs to avoid editing code.

## Fonts and colours
Edit `assets/style.css`:
- `--paper: #faf9f7` — background
- `--ink: #1e1c19` — text, including text over images
- `--font-serif` — large name display

The name is real text overlaid on top of images, **not** part of the images. Its colour is always dark; no white colour-switching or blend effect occurs.

## Content and provenance
The images here are **illustrative crops from AI-generated design mockups**, not images of Vanessa's real projects. Replace them with original/authorised project images, add project credits, and review all placeholders prior to public promotion. All project titles and news entries are clearly marked placeholders.
